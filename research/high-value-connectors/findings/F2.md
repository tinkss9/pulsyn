## Executive Summary

Based on data from DB-Engines (Dec 2025), Stack Overflow Developer Surveys (2024-2025), and Gartner Peer Insights, the top 10 databases by combined developer adoption + enterprise usage are:

1. **PostgreSQL** — 55.6% SO 2025 (+6.9pp YoY), DB-Engines #4, fastest-growing RDBMS
2. **MySQL** — 40.5% SO 2025, DB-Engines #2, still dominant in web/learning
3. **SQLite** — 37.5% SO 2025, embedded/mobile ubiquity
4. **Microsoft SQL Server** — 30.1% SO 2025, DB-Engines #3, 1981 Gartner reviews
5. **Redis** — 28% SO 2025 (+8pp YoY), DB-Engines #7, fastest-growing overall
6. **MongoDB** — 24% SO 2025, DB-Engines #5, 1219 Gartner reviews
7. **MariaDB** — 22.5% SO 2025, MySQL-compatible alternative
8. **Elasticsearch** — 16.7% SO 2025, DB-Engines #10, search/analytics
9. **Oracle** — 10.6% SO 2025, DB-Engines #1, 1163 Gartner reviews, enterprise standard
10. **DynamoDB** — 9.8% SO 2025, DB-Engines #18, 374 Gartner reviews, AWS-native

## 8. Recommendation for Pulsyn Connector Roadmap

**Immediate (MVP):** PostgreSQL, MySQL, SQL Server, MongoDB, Redis
- Covers ~85% of developer use cases and ~70% of enterprise workloads
- PostgreSQL alone covers Supabase, Aurora PG, Cloud SQL PG, Neon, PlanetScale (PG-compatible)

**Q2:** Oracle, Elasticsearch, DynamoDB, Snowflake, MariaDB
- Unlocks enterprise migration and cloud-native workloads

**Q3:** BigQuery, Cassandra, Cosmos DB, SQLite, Supabase
- Completes major cloud provider coverage

**Q4:** ClickHouse, CockroachDB, Neo4j, InfluxDB, Databricks
- Niche but high-value for specific verticals

**Note:** Many cloud databases (Aurora, Cloud SQL, Azure Database) expose standard PostgreSQL/MySQL wire protocols, so supporting PG and MySQL wire protocol implicitly covers 10+ managed cloud services.
