# High-Value Connectors for Pulsyn CDC Platform — Cross-Platform Research

> Generated 2026-08-07 · depth: standard · 59 sourced findings across 5 research angles · workspace: research/high-value-connectors/

## Executive Summary

- **PostgreSQL, MySQL, MongoDB, SQL Server, Oracle** are the universal "must-have" CDC source connectors — every major platform (Fivetran, Airbyte, Stitch, Estuary, Hevo, Qlik, Confluent, Debezium) treats them as first-class, production-grade connectors [1][2][3][4][5].
- **Snowflake, BigQuery, Amazon Redshift, Databricks** are the universal destination (materialization) connectors — present on every platform's featured list [4][5].
- Fivetran has **750+ connectors**; Airbyte has **620+**; Hevo has **150+**; Estuary has **~130 captures + ~50 materializations**; Stitch/Qlik has **100+** [1][2][3][4].
- **Salesforce, HubSpot, Stripe, Shopify, Google Ads, Facebook Ads, Google Analytics** are the top SaaS connectors across all platforms — these appear in every vendor's "featured" or "certified" list [1][2][3][4].
- Fivetran gates Oracle and High-Volume Agent connectors behind Enterprise pricing — signaling these are premium/high-value [1]. Airbyte gates SharePoint, Salesforce destination, and Workday behind Enterprise [2].
- **Debezium is the open-source CDC foundation** — Confluent, Estuary, and others explicitly build on its connectors. Its canonical set (MySQL, MariaDB, MongoDB, PostgreSQL, SQL Server, Oracle, Db2, Cassandra) represents the industry baseline [5].
- Airbyte exposes "Usage Rate" and "Sync Success Rate" publicly on connector pages — a transparency pattern Pulsyn should consider adopting [2].
- Estuary uniquely supports the **Airbyte connector specification** alongside its own gRPC protocol, enabling cross-platform interoperability [4].
- Fivetran now has an **AI Connector Agent (Beta)** that auto-generates connectors from REST API docs — competitive pressure for rapid connector development [1].

## What Platforms Prioritize for New Customers

### Fivetran
- **Pricing page showcases**: Facebook Ads, Google Analytics 4, Google Ads, Marketo (with exact MAR and cost data) — these are the connectors they use to sell [1]
- **Activation (reverse ETL) examples**: Snowflake → Salesforce, Snowflake → HubSpot [1]
- **Standard plan** ("Most Popular") includes 700+ connectors; Enterprise upgrades add Oracle, HVA connectors, and 1-minute syncs [1]
- **Connector SDK** available on all plans for custom Python connectors [1]
- **AI Connector Agent (Beta)** auto-generates connectors from REST API docs [1]

### Airbyte
- **Data replication landing page highlights**: PostgreSQL, MySQL, MongoDB, SQL Server (for CDC); Salesforce, HubSpot, Stripe, Shopify (for SaaS) [2]
- **Certified tier** (~55 connectors) represents Airbyte's "must-have" set — these are tested, vetted, production-ready [2]
- **Use-case taxonomy** for new users: Marketing Analytics, Sales & Support, Product Analytics, Finance & Ops, Engineering Analytics, Databases, Warehouses, Files, Unstructured [2]
- **All 600+ connectors available on all plans** — tier model is about quality, not access gating [2]
- **Agent Connectors** (Dec 2025) — new category for AI agent context, not just replication [2]

### Stitch Data (Qlik)
- **Featured databases**: PostgreSQL, MySQL, Oracle, SQL Server, MongoDB, DynamoDB [3]
- **Featured SaaS**: Salesforce, HubSpot, Google Ads, Facebook Ads, Google Analytics, Shopify, Jira, Intercom, Zendesk [3]
- **Two tiers**: Stitch-certified vs Community-supported [3]

### Hevo Data
- **Page ordering reveals priority**: Amazon RDS, PostgreSQL, MySQL, Oracle, MongoDB (first 5 featured), then Facebook Ads, Stripe, NetSuite, MS SQL Server, Salesforce, Google Ads, Intercom, Shopify [4]
- **Destinations limited to**: PostgreSQL, MySQL, MS SQL Server, BigQuery, Snowflake, Redshift, Databricks [4]
- **Three CDC modes**: log-based, timestamp-based, subset via SQL [4]

### Estuary
- **"High-scale technology systems" prioritized**: PostgreSQL, MySQL, MariaDB, MongoDB, SQL Server, Oracle, AlloyDB, BigQuery, Snowflake all support real-time CDC [4]
- **Open-source connectors** (Apache 2.0/MIT) — most extensible model [4]
- **Airbyte spec compatible** — any Airbyte connector can run on Estuary [4]

### Meltano Hub (Singer)
- **Most popular extractors**: PostgreSQL, REST API, CSV, Facebook Ads, Google Ads, GitHub, MongoDB, Shopify [3]
- **Most popular Singer taps by GitHub stars**: tap-google-sheets (35 stars), tap-zendesk (17), tap-exacttarget (14) [3]

## Open Questions

1. **Usage volume data**: No platform publishes aggregate "most used connector" rankings. Fivetran's MAR pricing examples are the closest proxy — Marketo's 847,574 MAR suggests high-volume enterprise use, while Facebook Ads at 34,479 MAR suggests broader but lighter adoption.
2. **CDC vs batch split**: Hevo's 150+ connectors mix CDC-capable and API-only sources; the exact breakdown is unclear. Pulsyn should clarify whether it's CDC-only or also batch replication.
3. **Connector maintenance cost**: The Singer ecosystem's fragmentation (206 repos, many abandoned) suggests maintenance burden varies wildly by connector. Which connectors break most on version upgrades?
4. **Enterprise gating strategy**: Both Fivetran and Airbyte gate premium connectors behind Enterprise tiers. Should Pulsyn follow this model or offer all connectors on all plans?
