# F5: Cross-Platform Connector Consensus — Universal Must-Haves

## Findings

### [1] PostgreSQL is the #1 universal database connector — present on every major ETL/CDC platform as a first-class, production-grade connector
- quote: "Fivetran's database connectors are our most important and battle-tested connectors." PostgreSQL listed as supported with Logical Replication as native CDC mechanism.
- url: https://fivetran.com/docs/connectors/databases
- source_type: primary
- published: 2026
- confidence: high

### [2] MySQL is the #2 universal database connector — supported by all 5 platforms (Debezium, Fivetran, Airbyte, Estuary, Confluent) with native binary log CDC
- quote: Fivetran lists MySQL with Binary Log as native CDC mechanism. Debezium lists MySQL as its first connector. Estuary lists MySQL as a primary Estuary-built connector with CDC support.
- url: https://fivetran.com/docs/connectors/databases/mysql
- source_type: primary
- published: 2026
- confidence: high

### [3] MongoDB is universally supported across all CDC/ETL platforms — Debezium, Fivetran, Airbyte, Estuary, and Confluent all offer first-class MongoDB connectors with change streams CDC
- quote: Debezium lists MongoDB as a source connector. Fivetran lists MongoDB with Change Streams as native CDC. Estuary lists MongoDB as a primary Estuary-built connector. Confluent lists MongoDB Atlas Source and MongoDB CDC Source (Debezium).
- url: https://debezium.io/documentation/reference/stable/connectors/mongodb.html
- source_type: primary
- published: 2026
- confidence: high

### [4] Microsoft SQL Server is universally supported — all 5 platforms offer CDC-capable SQL Server connectors using Change Data Capture or Change Tracking
- quote: Fivetran lists SQL Server with CDC and Change Tracking as native incremental sync methods. Confluent lists "Microsoft SQL Server CDC Source V2 (Debezium)" and "Microsoft SQL Server Source (JDBC)". Debezium lists SQL Server as a source connector.
- url: https://fivetran.com/docs/connectors/databases/sql-server
- source_type: primary
- published: 2026
- confidence: high

### [5] Oracle is universally supported across all CDC/ETL platforms — Debezium, Fivetran, Airbyte, Estuary, and Confluent all offer Oracle CDC connectors
- quote: Confluent lists both "Oracle XStream CDC Source" and "Oracle CDC Source" as managed connectors. Fivetran lists Oracle with LogMiner and proprietary Binary Log Reader/Fivetran Teleport Sync methods. Estuary lists OracleDB as a primary Estuary-built connector.
- url: https://docs.confluent.io/cloud/current/connectors/cc-oracle-cdc-source.html
- source_type: primary
- published: 2026
- confidence: high

### [6] BigQuery and Snowflake are the two universally supported cloud data warehouse destinations — both appear as source and destination on every major platform
- quote: Fivetran lists BigQuery (with Time Travel CDC) and Snowflake (with Time Travel CDC) as database connectors. Confluent lists both BigQuery Sink and Snowflake Sink as managed connectors. Estuary lists BigQuery and Snowflake as capture connectors.
- url: https://fivetran.com/docs/connectors/databases/bigquery
- source_type: primary
- published: 2026
- confidence: high

### [7] Debezium's canonical CDC connector set (MySQL, MariaDB, MongoDB, PostgreSQL, SQL Server, Oracle, Db2, Cassandra) represents the industry's baseline for open-source CDC — most commercial platforms build on or integrate Debezium
- quote: "Debezium provides a growing library of source connectors that capture changes from a variety of database management systems." Lists 13 connectors: MongoDB, MariaDB, MySQL, PostgreSQL, SQL Server, Oracle, Db2, Cassandra, Vitess, Spanner, Informix, CockroachDB.
- url: https://debezium.io/documentation/reference/stable/connectors/index.html
- source_type: primary
- published: 2026 (v3.6)
- confidence: high

### [8] Confluent Cloud offers the broadest managed CDC connector set among streaming platforms — 60+ managed connectors with Debezium-based CDC for MySQL, PostgreSQL, SQL Server, MongoDB, Oracle, MariaDB, and Db2
- quote: Confluent Cloud connector list includes MySQL CDC Source V2 (Debezium), PostgreSQL CDC Source V2 (Debezium), SQL Server CDC Source V2 (Debezium), MongoDB CDC Source (Debezium), MariaDB CDC Source (Debezium), Oracle CDC Source, Oracle XStream CDC Source, and Db2 Source (JDBC).
- url: https://docs.confluent.io/cloud/current/connectors/index.html
- source_type: primary
- published: 2026
- confidence: high

### [9] Fivetran supports 24 database connectors including niche databases like SAP, Elasticsearch, Firebase, and CockroachDB — the broadest database connector catalog among commercial ETL platforms
- quote: Fivetran's database connector list includes Amazon DocumentDB, Amazon DynamoDB, Azure Cosmos DB, BigQuery, CockroachDB, Convex, Databricks, Db2 for i/LUW/z/OS, Elasticsearch, Epic Clarity, Firebase, MariaDB, MongoDB, MySQL, OpenSearch, Oracle, PlanetScale, PostgreSQL, SAP, SingleStore, Snowflake, SQL Server.
- url: https://fivetran.com/docs/connectors/databases
- source_type: primary
- published: 2026
- confidence: high

### [10] Amazon DynamoDB, MariaDB, and Db2 are the "Tier 2" database connectors — supported by 3-4 of the 5 major platforms but not universally
- quote: Fivetran lists Amazon DynamoDB (with DynamoDB Streams CDC), MariaDB (with Binary Log CDC), and Db2 (for i, LUW, z/OS). Debezium lists MariaDB and Db2. Confluent lists DynamoDB CDC Source and MariaDB CDC Source (Debezium). Estuary lists MariaDB and DynamoDB.
- url: https://fivetran.com/docs/connectors/databases/dynamodb
- source_type: primary
- published: 2026
- confidence: high

### [11] Estuary prioritizes "high-scale technology systems" for first-party connector development — their Estuary-built connectors (PostgreSQL, MySQL, MariaDB, MongoDB, SQL Server, Oracle, AlloyDB, BigQuery, Snowflake) all support real-time CDC
- quote: "We prioritize high-scale technology systems for development. All Estuary connectors capture data in real time, as it appears in the source system."
- url: https://docs.estuary.dev/reference/Connectors/capture-connectors/
- source_type: primary
- published: 2026
- confidence: high

### [12] Airbyte claims 620+ connectors total (sources + destinations), making it the largest connector catalog — but many are community-contributed with varying quality
- quote: "600+ Replication Connectors and counting, 50+ Agent Connectors with more shipping weekly."
- url: https://airbyte.com/connectors
- source_type: primary
- published: 2026
- confidence: high
