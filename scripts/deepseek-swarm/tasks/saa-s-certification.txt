# Task: Certify Top SaaS Connectors with Real API Tests

## Objective
Certify Stripe, Salesforce, and HubSpot connectors with real API integration tests against sandbox/test environments.

## Current State
- These connectors exist in `packages/core/src/connectors/` (stripe.ts, salesforce.ts, hubspot.ts)
- They use the SaaSConnector base class which handles auth, pagination, rate limiting, CDC polling
- They have real API endpoints defined but haven't been tested against live APIs
- The cert-matrix.json shows them as "CERTIFIED" but with Lane A (SaaS) classification

## What Needs to Be Done

### 1. Stripe (Easiest — has test mode)
- Stripe has a test mode with test API keys
- Create test at `packages/core/src/__tests__/connectors/stripe.test.ts`
- Test: connect, getTables, getTableSchema, extractFull (customers, charges, invoices)
- Use Stripe test API key: `sk_test_...`
- Verify: pagination works, rate limiting works, CDC polling works

### 2. Salesforce (Has sandbox)
- Salesforce has Developer Edition (free) and sandbox environments
- Create test at `packages/core/src/__tests__/connectors/salesforce.test.ts`
- Test: connect via OAuth2, getTables, getTableSchema, extractFull (accounts, contacts, opportunities)
- Use Salesforce sandbox credentials
- Verify: SOQL queries work, pagination works

### 3. HubSpot (Has test portal)
- HubSpot has a free test portal with API access
- Create test at `packages/core/src/__tests__/connectors/hubspot.test.ts`
- Test: connect, getTables, getTableSchema, extractFull (contacts, companies, deals)
- Use HubSpot test API key
- Verify: CRM API works, pagination works
