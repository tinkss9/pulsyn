# Pulsyn Viral Loops

Specific mechanics to make Pulsyn spread organically. Each loop is self-reinforcing: use → visibility → new user → use.

---

## 1. Share Buttons

### In-App Share Points

| Location | Share Action | Pre-filled Text |
|----------|-------------|-----------------|
| **Pipeline created** | "Share your new pipeline" | "Just set up real-time CDC with @Pulsyn — {source} to {target} in 3 clicks. #DataEngineering" |
| **Milestone reached** | "Celebrate your milestone" | "Replicated {N} rows with @Pulsyn! Real-time CDC without the Kafka headache. #CDC" |
| **Connector certified** | "Share your connector" | "Just certified the {connector} connector for @Pulsyn. 320 and counting! #OpenSource" |
| **Dashboard snapshot** | "Share your dashboard" | "My Pulsyn dashboard — {N} pipelines, {latency}ms latency, 100% uptime. #DataOps" |
| **Referral page** | "Invite a friend" | "I use Pulsyn for real-time data replication. Try it free: {referral_link}" |

### Implementation

- Twitter Web Intent API — no auth needed, just a URL with query params
- LinkedIn Share API — same pattern
- Copy-to-clipboard fallback for all platforms
- Track share clicks and resulting signups per channel

### Expected Viral Coefficient: +0.05 (5% of active users share per month)

## 2. Embed Widgets

### Pipeline Status Badge

```html
<a href="https://pulsyn.io">
  <img src="https://pulsyn.io/badge/{pipeline_id}/status.svg" alt="Pulsyn Pipeline Status" />
</a>
```

- Shows: pipeline name, status (active/paused/error), rows replicated, latency
- Use case: README files, internal dashboards, status pages
- Branding: "Powered by Pulsyn" in the badge

### Connector Certification Badge

```html
<a href="https://pulsyn.io/connectors/{connector_name}">
  <img src="https://pulsyn.io/badge/certified/{connector_name}.svg" alt="Pulsyn Certified Connector" />
</a>
```

- Shows: certification status, pass rate, connector version
- Use case: GitHub repos for custom connectors, community connectors
- Viral loop: connector authors display badge → their users discover Pulsyn

### Data Pipeline Widget

```html
<iframe src="https://pulsyn.io/embed/pipeline/{pipeline_id}" width="600" height="400"></iframe>
```

- Shows: live pipeline visualization (source → transform → destination)
- Use case: internal team dashboards, Notion pages, Confluence
- Branding: "Powered by Pulsyn" footer with link

### Expected Viral Coefficient: +0.03 (each badge/widget generates ~3 impressions/month)

## 3. API Playground

### Interactive API Explorer

**URL:** `pulsyn.io/playground`

**Features:**
- Pre-populated with sample API calls (list pipelines, create connector, start replication)
- Live API key (sandbox environment, no real data)
- Copy-as-cURL, Copy-as-Python, Copy-as-Node buttons
- Response viewer with syntax highlighting
- Share button: "Try this API call in Pulsyn Playground"

**Viral Mechanic:**
1. Developer finds Pulsyn via search/HN/Reddit
2. Opens playground, tests API without signup
3. Shares playground link with team: "Check out this CDC API"
4. Team members try it → some sign up
5. Shared playground links include UTM tracking

### MCP Playground

**URL:** `pulsyn.io/mcp-playground`

**Features:**
- Live MCP server connection (sandbox)
- Try any of the 26 MCP tools
- See tool schemas and responses
- Copy MCP config for Claude/Cursor/etc.

**Viral Mechanic:**
1. AI-native developer discovers MCP playground
2. Tests it with their AI coding assistant
3. Shares config snippet: "Add this to your .mcp.json for CDC"
4. Other developers add Pulsyn MCP to their setup

### Expected Viral Coefficient: +0.08 (playground users convert at 15%, share at 20%)

## 4. "Powered by Pulsyn" Badge

### Placement Strategy

| Surface | Badge Style | Visibility |
|---------|------------|------------|
| **Web dashboard** | Small footer badge | All dashboard visitors |
| **Email reports** | "Data by Pulsyn" in email footer | All report recipients |
| **API responses** | `X-Powered-By: Pulsyn` header | All API consumers |
| **CLI output** | "Powered by Pulsyn v0.1.0" on `--version` | All CLI users |
| **Export files** | "Generated by Pulsyn" in CSV/JSON exports | All export recipients |

### Badge Design

- Minimal, non-intrusive
- Links to `pulsyn.io` with UTM: `?utm_source=badge&utm_medium=product&utm_campaign=powered_by`
- Two versions: full logo + text, and icon-only
- Light and dark mode variants

### Opt-Out Policy

- **Free tier:** Badge is always visible (part of free tier value exchange)
- **Pro tier:** Badge is optional (can be disabled in settings)
- **Business/Enterprise:** Badge is removed by default

### Expected Viral Coefficient: +0.10 (badge seen by 10x the user base, 1% click-through)

## 5. Open Source Fork Loop

### How It Works

1. Pulsyn core engine is Apache 2.0 on GitHub
2. Developer forks and self-hosts
3. Fork shows up in GitHub "Used by" and "Forks" count
4. Social proof: "1,200 forks" → more developers discover Pulsyn
5. Some forkers contribute back → better product
6. Some forkers switch to hosted version → revenue

### Amplification

- **GitHub README:** Prominent "Deploy to Docker" button
- **Awesome lists:** Submit to awesome-data-engineering, awesome-cdc, etc.
- **GitHub Topics:** Tag repo with `cdc`, `data-replication`, `change-data-capture`, `real-time`
- **Star history:** Track and share star milestones on Twitter

### Expected Viral Coefficient: +0.04 (each fork = ~5 impressions via GitHub network)

## 6. Content-Driven Viral Loops

### Tutorial Viral Loop

1. Write tutorial: "Postgres to Snowflake in 3 Minutes with Pulsyn"
2. Reader follows tutorial, succeeds
3. Reader shares tutorial with team
4. Team members try it → some sign up
5. Reader writes their own blog post referencing Pulsyn → SEO boost

### Comparison Page Viral Loop

1. User searches "debezium alternatives"
2. Finds Pulsyn comparison page
3. Tries Pulsyn, finds it easier
4. Writes review on G2/Capterra/Reddit
5. Review drives more search traffic

### Template Viral Loop

1. Publish pipeline templates: "E-commerce CDC: Shopify → Postgres → BigQuery"
2. User clones template
3. Customizes for their stack
4. Shares customized version with community
5. Community member tries Pulsyn to use the template

### Expected Viral Coefficient: +0.06 (content compounds over time)
